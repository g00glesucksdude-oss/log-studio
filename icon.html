How do I get a token?
  1. Open GitHub › new fine-grained token.
  2. Resource owner: the owner above. Repository access: Only select repositories → pick this repo.
  3. Permissions › Repository › Contents: Read and write.
  4. Generate, copy it, paste it above. Only someone with write access to the repo can publish.
The token goes straight from your browser to api.github.com and nowhere else.
